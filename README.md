# 387 News — редакционная версия 4.1

Нормативный документ: [редакционная политика v4.1](docs/editorial-policy-v4.1.md). [Матрица изменений и результаты](docs/POLICY_V41_IMPLEMENTATION.md). [Эксплуатация, права, миграция и откат](docs/POLICY_V41_OPERATIONS.md).

Владелец26октября2026 разрешил прямое внедрение v4.1 в production через PR№7 без отдельного trial. Исторические выпуски сохраняются. [Фактический статус rollout](docs/PRODUCTION_V41_ROLLOUT.md).

Конвейер: поиск кандидатов → полный оригинал → документальные права текста/картинок → A (полный русский оригинал), B (полный перевод) или C (самостоятельная русская статья) → независимый фактчекинг → смысловая полнота → литературная проверка → композиция 12 статей → приватная сборка → публикация с 06:00 Europe/Moscow.

Обязательны «Семья», «Москва и путешествия», «Здоровье и движение». 20 приоритетов, рекомендательные очерки, резерв и время заданы в `config/editorial.json`. Редакционных нормативов длины нет. Технические части обрабатываются полностью и сохраняются между запусками. Для C разрешение на неохраняемые факты не требуется; самостоятельность проверяется отдельно, спорное использование блокируется. Неполный/непроверенный номер остаётся закрытым; действующий сайт сохраняется.

Проверки без Gemini и production:

```sh
python -m pip install 'cryptography>=44,<49'
python -m py_compile scripts/*.py
python -m unittest discover -s scripts -p 'test_*.py' -v
```

Тесты используют вымышленные тексты, моки HTTP/модели и временные каталоги. Локально не восстанавливать реальные закрытые checkpoints и не экспортировать Secrets. Восстановление и подготовка настоящих материалов выполняются только существующим production GitHub Actions из main; отдельный preview/trial не обязателен.

Pages должен публиковаться через **GitHub Actions**, из пакета `site_checks.py --package`, содержащего только финальный сайт (`index.html`, `assets`, `archive`, `issues`, `CNAME`, `robots.txt`, `sitemap.xml`). Публикация всей ветки из корня не подходит. Настройка Pages Source требует владельца репозитория.

> Исторические инструменты trial/Codespaces/owner-reader оставлены для совместимости; они не запускаются автоматически и не являются условием production. Актуальные инструкции — [эксплуатация v4.1](docs/POLICY_V41_OPERATIONS.md).
