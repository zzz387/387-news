# 387 News · версия 2.0 — для 387.su

Готовый статический сайт с пилотным выпуском №001 от 23 октября 2026 года. Не требует платного хостинга; рассчитан на GitHub Pages. Дополнительно нужен лишь оплачиваемый пользователем домен 387.su.

## Размещение

1. Распакуйте архив и загрузите всё его содержимое (не саму папку) в публичный GitHub-репозиторий.
2. В GitHub откройте Settings → Pages и включите публикацию из ветки main, корень /.
3. В настройках Pages проверьте custom domain 387.su. Файл CNAME уже включён.
4. Направьте DNS домена на GitHub Pages по актуальной официальной документации GitHub.
5. Включите Enforce HTTPS, когда GitHub закончит выпуск сертификата.

Главная: `/`. Архив: `/archive/`. Обзор выпуска: `/issues/2026-10-23/`. Страницы десяти статей находятся в `/issues/2026-10-23/articles/`.

Сайт проверен на макетах шириной 320, 390 и 1440 пикселей на отсутствие горизонтального переполнения и битых локальных ссылок. Иллюстрации являются оригинальными редакционными SVG-композициями, а не фото реальных событий. В статьях приведены ссылки на первоисточники. Для офлайн-проверки: `python -m http.server 8000` и откройте `http://localhost:8000`.

**Важно:** сайт статический. Периодическая подготовка номера в ChatGPT сама по себе НЕ публикует его на 387.su. Автоматическое добавление выпусков потребует отдельной интеграции. До её настройки публиковать новые файлы на GitHub нужно вручную.

Личная редакционная политика хранится отдельно, в этот публичный ZIP не включена.
