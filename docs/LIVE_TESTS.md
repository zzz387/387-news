## Практические ограничения

Реальных 429/503 в этом испытании не было: их безопасное откладывание, учёт запросов и восстановление cooldown проверены инъекцией HTTP-ошибок в unittest. Фактические лимиты Free Tier и расписание GitHub не гарантируются приложением. При SIGKILL/потере runner до успешной выгрузки можно потерять последнюю порцию работы; обычный SIGTERM проверен тестом с настоящим сигналом. Артефакты хранятся семь дней. Модельный review не гарантирует достоверность; недостаток доказательств блокирует выпуск. Перед включением производства отключите старые workflows по инструкции.
