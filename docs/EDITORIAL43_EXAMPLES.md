Маленькие новости, от которых мир становится интереснее

**Билет для дождевого червя.** В вымышленном музее посетители перенесли червя с
высохшей дорожки на влажную клумбу. Сотрудники в шутку назвали это самой короткой
экскурсией дня. Источник: синтетическая демонстрация, example.org/demo/worm.

**Ворона с отделом находок.** В вымышленном парке ворона принесла смотрителю
блестящую пуговицу. Смотритель устроил рядом маленькую коробку для находок.
Источник: синтетическая демонстрация, example.org/demo/crow.

**Библиотека для семечек.** В вымышленном дворе соседи обменялись подписанными
пакетиками семян. Вместо читательского билета пригодился бумажный конверт.
Источник: синтетическая демонстрация, example.org/demo/seeds.
