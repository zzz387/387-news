# Codex — реализовать короткую редакционную политику 387 News 4.3

**Основной документ:** `docs/editorial-policy-v4.3.md`. Это не задача переписать промпты: устранить технические причины отсутствия выпуска. Разрешение на изменение production этим документом **не выдаётся**. Сначала в отдельной ветке внедри и протестируй, затем подготовь безопасный переход.

1. **Убрать жёсткое количество статей в новом выпуске:** 12 — целевой ориентир, публиковать 1+ допущенных статей; динамический счётчик, первая полоса, архив, генератор HTML, проверки `site_checks`. Допускать 9, 12 и 13+, но **не ждать** дополнительных. Особый контракт №003-R не должен устанавливать обязательный минимум для ежедневного выпуска.
2. **Резерв без Gemini:** при отсутствии готовой статьи создать честный выпуск «Обзор источников» из предварительно проверенных URL/заголовков/дат/изданий. Не копировать защищённый текст; не выдумывать содержание. Желательно заранее поддерживать набор собственных evergreen-заметок, проверенный по фактам, правам и актуальности. При пустом резерве или поломке внешней инфраструктуры зафиксировать инцидент, не заявлять фиктивную публикацию.
3. **Упростить редакционный шлюз:** для C позволить короткий самостоятельный материал по любому проверенному узкому аспекту; не требовать `requirements` всего источника, «21 игру» из чужого заголовка, жёсткой глубины. Одна финальная проверка **существенных фактов, безопасности, прав и соответствия заголовка** вместо циклических AI-аудитов каждого куска. A/B — законные полные оригинал/перевод, если так обозначены. Медицинские/детские практические советы по-прежнему требуют компетентной доказательной базы.
4. **Не допускать вечных ремонтов:** формат блоков нормализуется локально; буквальные повторы убираются без потери смысла; лимит 1–2 попытки исправления; после этого кандидат откладывается. Одна отклонённая статья не удаляет одобренные.
5. **Приоритет daily:** приостановить расход Gemini на №003-R и любые special до успешного выпуска ежедневной газеты (с сохранением special ciphertext, ledger и history); не сбрасывать счётчики и не переписывать исторический №003. Не обещать специальных выпусков, пока daily нестабилен.
6. **Суточная доставка:** 06:00 Москва, приоритет публикации уже подготовленного. Старейший незавершённый выпуск не должен бесконечно блокировать последующие: введи явный, безопасный порядок закрытия/архивации очереди без потери данных и без публикации задним числом как «сегодня». Если Gemini/квота недоступны, не останавливать весь выпуск.
7. **Проверки:** реальные регрессионные тесты для 0,1,3,7,8,12,13 статей; ноль готовых → честный обзор ссылок; отсутствие Gemini/220 исчерпано → резерв; special не отнимает квоту daily; материал с неподтверждённым медицинским советом не попадает в выпуск; исторический архив не изменяется; повторный запуск не дублирует публикацию и не теряет готовые тексты.
8. **Отчёт:** показать причины прежнего 220/220 (48 daily +172 special) и 0/8; текущую готовность ежедневного выпуска, фактическую публикацию по HTTPS, изменённые файлы, тесты и риски. Не выдавать зелёные тесты за опубликованную газету. Запрещены новые Secrets, увеличение лимитов, force push, обход прав/коммерческих ограничений.

**Ключевой критерий:** при восьми, трёх или одной безопасной статье номер выходит вовремя; при отсутствии статей выходит честный резервный обзор источников. Технические сбои Pages нельзя гарантированно исключить — при них требуется мониторинг, повторная доставка и прозрачная диагностика.
