## Briefs

New unpublished issues use `brief_policy_revision=2`: minimum eight, maximum twelve.
All eligible notes remain in the checkpoint; reusable surplus is banked in the
existing encrypted stock. No new database or publisher catalog is introduced.
Selection uses soft subject/publisher penalties and same-event deduplication.
Animal stories are allowed, but alternative subjects receive preference after a
few animal stories. There are no mandatory per-topic quotas.

Story-level criminal/tragedy exclusion is applied during discovery, before a
batch request, during admission and before selection. Strong crime phrases,
institution/action combinations and explicit crime sections are considered.
Benign police mentions are allowed; no publisher is excluded wholesale. Facts,
source binding, dates, safety and rights remain mandatory, without literary audits.
Old immutable 4.4 manifests lacking the revision retain their historical limits;
the current homepage can display a newly filtered selection without altering them.

## Artwork and availability

`mosaic44` selects up to twelve diverse approved articles, not their first twelve
positions. Genre, palette, composition and aspect ratio are chosen by association.
The cache identity binds article identity, description hash, genre, ratio and
prompt version. Stored choices are sticky. Titles remain HTML text and all tiles
are ordinary keyboard-accessible article links. Images are labelled AI artwork.

The initial nine pictures for the public November 18 issue were generated once
using the existing ChatGPT image-generation tool, then encoded as WebP. Their
combined size is about 1.8 MB; no new paid service or Gemini image request was used.
The tool's per-picture monetary cost is not exposed here, so no zero-price claim
is made. Its availability in this chat does **not** expose an unattended Actions API.

**Automatic image generation is not connected:** `provider=disabled`, no image
model configured, free image-model access unverified. Existing Flash-Lite text
models are not treated as image generators. A concrete callable image model with
verified free access is needed to enable the prepared adapter. Do not set
`free_tier_verified` merely because a model supports text generation; check the
specific image model's permissions, response format, billing and quota first.
Paid image models require separate owner approval.

The disabled adapter makes zero API requests. The prepared Gemini adapter runs
only on protected main in Actions, reuses the existing Secret and shared ledger,
reserves each attempt, honors the existing intervals, and defers after429/503.
It is limited to one new image per run and bounded failure attempts. Image work
is optional, starts after the issue's required content is ready, and does not
delay the due release. Missing art produces a readable text tile and a diagnostic
state. Once an approved free provider is configured, ordinary production windows
resume saved work; checked public artwork is reused without another request.

Unpublished generated bytes stay in encrypted checkpoints. Only verified finished
WebP files and public provenance enter `assets/illustrations/YYYY-MM-DD/`.
Published files have permanent content-addressed names and hashes. A small script
can enhance missing art from a verified public manifest without rewriting archived
HTML; failed images retain the title link. The current homepage can improve while
the original overview and release manifest remain byte-identical.
