## Источники и восстановление

Исходный статический пул имел 13 кандидатов при цели 12 + 2 резерва. Проверены предложения по всем 20 приоритетным направлениям. В активный `config/candidates.json` включены только 33 записи, прошедших полное извлечение и rights gate в Actions; 32 URL в момент проверки не встречались в опубликованном архиве. Подробности, отказы и тематическое покрытие сохранены в [техническом JSON](source-reserve-2026-10-27.json). Это проверка доступности и допустимого режима работы, не одобрение будущих статей или всех их фактических утверждений.

Проверены также указанные независимые страницы для здоровья и семьи. Проверки фактов, контекстной применимости, полноты, литературного качества и прав остаются обязательными при подготовке каждой статьи. Пул конечен; его размер не гарантирует ежедневную достаточность после редакционных отказов и исключения использованных сюжетов.

Сохранённый daily checkpoint теперь подхватывает добавленные кандидаты без повторного RSS-discovery и без сброса принятых материалов. При исчерпанном бюджете состояние кандидатов не меняется. Уже опубликованный первоисточник отсеивается до обращения к модели. Public source checks кэшируют robots и соблюдают паузы по origin; HTTP 429/503 прекращает обращения к тому же origin до следующей независимой проверки.

Добавлены узкие адаптеры NIST, ДМТЮА и полного исследовательского текста Frontiers (с обязательными Methods/Results) для явно установленных контейнеров полного текста. Проверка закрывающей границы остаётся обязательной; нет fallback на аннотацию, search snippet, всю страницу или обход доступа. Для проверенной русской страницы Банка России без html lang применяется узкое правило домена /dkp/ и преобладания кириллицы; на другие сайты оно не распространяется; отсутствие даты/автора сохраняется явно. Строгая актуальность новостей не изменена.

## №003-R

Сохранены восемь тем и неизменный публичный оригинал №003. Неиспользованные mos.ru/CDC записываются как `unused_original_urls`; они не считаются прочитанными и не становятся источниками фактов. Альтернативные планы используют доступные публикации АГН, UNICEF, театр и полные исследования. Для альтернатив применяется только самостоятельная статья, режим C. Исследование о кофе 2025 года не выдаётся за исходную работу 2026 года; неподтверждённый рост 40% не переносится в новый текст.

Миграция отдельного special checkpoint выполняется только внутри Actions: общий quota snapshot, принятые части неизменённых слотов и вся прежняя история сохраняются. Старые состояния изменённых источников сохраняются внутри ciphertext для проверки. Отказы извлечения/доступности имеют максимум три попытки; robots-forbidden и правовые сомнения не обходятся. Публикация остаётся невозможной до 8/8 и полного аудита.

## Монитор и внедрение

Read-only health вычисляет московскую производственную дату и старейший незавершённый номер по тем же правилам, что production. Проверяется фактически опубликованный выпуск, а не фиксированные даты 26/27 октября. При смене UTC-дня допустимо прочитать предыдущий ledger без записи и без сброса; расход текущих суток показывается отдельно. Закрытый daily checkpoint монитор не скачивает.

Merge с отметкой `[maintenance only]` устанавливает проверенный код и запускает read-only health без daily prepare, special generation и deployment. Это исключает дублирование реального schedule-запуска, который появился 27 октября в 00:38 МСК: [40405990516](https://github.com/zzz387/387-news/actions/runs/40405990516). Следующие schedule-окна работают как прежде под общим mutex. Ни CI, ни checkpoint не означают готовность выпуска; фактические статьи и публикация проверяются отдельно.

Повторные source checks выявили переменную доступность PMC: вместо полного текста иногда возвращается посторонняя страница. Такие ответы удерживаются, не считаются оригиналом. Для семейного материала предложен полный первичный PLOS, для кофе — другое открытое исследование Frontiers 2025 года. Оба требуют отдельной технической проверки и всех редакционных gates. PLOS включён в компетентные источники первичных исследований для не-медицинских тем; специальные правила авторитетных медицинских подтверждений не изменены.

Обновление: 27 октября в 00:38:01 МСК API зарегистрировал настоящее событие schedule. Переменная SCHEDULE указывает cron-выражение, но одна строка охватывает несколько часов. Без отдельного scheduled_at даже совпавшая строка не позволяет однозначно отличить задержанное окно 22:17 от окна 00:17. Время создания не следует выдавать за точное время планового события.

## Реальный запуск после восстановления API

[40405990516](https://github.com/zzz387/387-news/actions/runs/40405990516) создан 27 октября в 00:38:01 МСК. Он получил cron `17 9,11,13,15,17,19,21,22 * * *`, общий для окон 22:17 и 00:17; отдельный scheduled_at в Runs API отсутствует. Поэтому однозначное отнесение к одному из этих окон не доказано.

В этом run Gemini обслужил 24 обращения без прежнего HTTP 503. Ledger вырос с 5 до 29/220; готовых статей по-прежнему 0/12. Причина остановки стала другой: восемь кандидатов получили ограниченные повторы отказов CLAIM_NOT_IN_ORIGINAL/EVENT_DATE_UNVERIFIED, затем исчерпан лимит 24/run. Прогресс и отказы сохранены; следующий controller wake — 01:17 МСК. Успех job не является готовым номером.

Добавлен протокол доказательств по идентификаторам. Из полного исходного текста программа выделяет дословные фрагменты, модель выбирает `evidence_id`, а точные quote/source_id привязывает программа. Это устраняет необходимость генеративно перепечатывать английскую цитату и непрозрачный hash. Неизвестный идентификатор, отсутствие требуемого свидетельства даты, неполное покрытие, неподтверждённые факты и литературные отказы продолжают блокировать материал. Legacy-ответы с точной цитатой поддерживаются. Успешные старые анализы и их cache не сбрасываются; предел трёх неудачных попыток, 24/run и 220/day сохраняется. Отвергнутый ответ хранится только в encrypted checkpoint; безопасный лог содержит код/тип ошибки и номер попытки, без цитат и досье.

Новый протокол проверен синтетическими регрессиями; факт успешной подготовки реальной статьи после его включения должен подтверждаться следующим штатным production, а не этим CI.

Финальный активный пул дополнительно исключает семейные материалы без независимого компетентного подтверждения и индекс Apollo Lunar Surface Journal, который не является выбранной полноценной публикацией. Итог: 33 кандидата по 20 направлениям, 32 URL ещё не использованы в архиве на момент проверки.
